# Helmet Detection System

A Python-based helmet detection and traffic violation monitoring project using YOLO object detection.

## Features
- Detects helmet and no-helmet riders
- Uses YOLO for object detection
- Stores violation information
- CSV logging system
- Dataset preprocessing scripts included

## Technologies Used
- Python
- YOLOv8 / YOLO
- OpenCV
- YAML

## Project Files

| File | Purpose |
|------|---------|
| detect.py | Runs helmet detection |
| train.py | Model training script |
| data.yaml | Dataset configuration |
| check_labels.py | Label checking utility |
| split_dataset_fixed.py | Dataset splitting |
| convert_to_yolo_fixed.py | Annotation conversion |

## Dataset
Dataset files, annotations, training images, and model weights are excluded from this repository because of size limitations.
